# dotfiles

## Setup

If you setup config files, use `make` command for setting symbolic links.
See [Makefile](./Makefile).

## Format config files

- In `nvim`, use `stylua` to format lua files.
- In `zed`, use `Biome` to format JSON files.
  Just run `pnpm run lint`.
